episodemandatory

Container for AF-burden assessment. One row per aggregated monitoring window or per disaggregated arrhythmia episode, distinguished by episode_type_concept_id.

Fields to populate

episode_idrequired
Primary key. episode_event and the custom extension tables key on it.
person_idrequired
→ person
Foreign key to person.
episode_concept_idrequired
concept
Distinguishes an aggregated AF-burden window (2000011002) from a disaggregated AF episode (2000011003); the whole AF-burden architecture depends on this discriminator. Where the specific arrhythmia type is known, an AF or atrial arrhythmia concept (e.g. 313217) may be used instead.
episode_start_daterequired
Opens the monitoring window. AF burden is meaningless without the interval it was measured over.
episode_end_daterequired
Closes the monitoring window. Nullable in the CDM, but a burden percentage over an open-ended interval cannot be interpreted, so AFBSTEP requires it.
episode_numberexpected
Orders repeated episodes within a person. Absent where a site reports a single aggregated window.
episode_object_concept_idrequired
concept
What the episode is about. Required by the CDM.
episode_type_concept_idrequired
concept
Provenance of the record. Pinned to 32828 (EHR episode record), reflecting that episode rows are device-/EHR-generated rather than derived from a manually completed case report form, unlike measurement rows (32809).

observation_periodmandatory

Defines the window in which the absence of a record is interpretable. Without it a missing condition cannot be distinguished from an unobserved stretch of time.

Fields to populate

Primary key.
person_idrequired
→ person

personmandatory

Every AFBSTEP analysis is per-person. No other table can be interpreted without it.

Fields to populate

person_idrequired
Primary key. Every other table joins on it.
gender_concept_idrequired
concept
Pinned to MALE/FEMALE. Used as a stratifier in every planned analysis.
year_of_birthrequired
Age at index is derived from it. No analysis is interpretable without age.
birth_datetimeoptional
Finer precision than year_of_birth is not required by any AFBSTEP analysis, and full dates of birth are avoided where they are not needed.
race_concept_idoptional
concept
NOT NULL in the CDM so a value must be present, but AFBSTEP does not require it to be informative; concept 0 is acceptable where a site does not collect it.
ethnicity_concept_idoptional
concept
Same as race_concept_id: required by the DDL, not required to be informative by AFBSTEP.
person_source_valueexpected
Pseudonymised site identifier. Needed to trace a record back to the source system during mapping review.
